Scaling_experiment documentation
Documented Observations & Key InsightsWhen you evaluate the output data across your dimension boundaries, you will capture the following trend behaviors:1. Score Ranges Expand Dramaticallyd_k = 8: Raw score variations are tiny (e.g., [-4.72, 5.60]).d_k = 512: Raw score ranges widen significantly (e.g., [-26.39, 35.75]).Why: Dot products multiply and sum elements. If components are independent random variables with zero mean and unit variance, their dot product has a mean of 0 and a variance equal to \(d_{k}\). As dimensions scale, variance grows, causing scores to drift into massive values.2. Maximum Probability Over-PeakingUnscaled d_k = 512: The peak probability hits a hard 1.0000, while the rest of the row reads exactly 0.0000.Scaled d_k = 512: The maximum probability scales down to a healthy 0.5812, allowing multiple contextual elements to be weighted simultaneously.3. Distribution Sharpness & Gradient VanishingThe Hazard: Passing a score like 35.75 into the exponent function pushes its value to \(e^{35.75}\), making it entirely dominant over other items.The Structural Collapse: This changes your soft attention distribution into a hard, rigid argmax assignment. When this happens, the mathematical derivative (gradient) of the softmax layer drops to almost zero. Without scaling, larger models completely halt backpropagation updates during training. Dividing by \(\sqrt{d_{k}}\) pulls variance back down to a constant unit value of \(1\), protecting gradient flow.

Why does \(QK^{T}\) produce token-to-token relationships?Matrix multiplication between a Query matrix \(Q\) of shape (N, d_k) and a transposed Key matrix \(K^{T}\) of shape (d_k, N) performs a dot product between every single row index in \(Q\) and every single column index in \(K^{T}\) [INDEX].Mathematically, the entry at row \(i\), column \(j\) in the resulting (N, N) attention score matrix is calculated as [INDEX]:\(\text{Score}_{i,j}=\vec{q}_{i}\cdot \vec{k}_{j}\)Because the dot product acts as a geometric metric of alignment, a larger positive score indicates that the search requirements of token \(i\) (\(q_{i}\)) align tightly with the features displayed by token \(j\) (\(k_{j}\)) [INDEX, INDEX]. The rows represent the active token asking for info, while the columns represent the matching target tokens being attended to [INDEX].3. Why does increasing \(d_{k}\) affect softmax behavior?When the dimensionality \(d_{k}\) of your hidden features grows large, the numerical magnitude of the raw dot products scales up heavily [INDEX, INDEX]. If the individual elements of your \(Q\) and \(K\) vectors are independent random variables with a mean of \(0\) and a variance of \(1\), their resulting dot product will have a mean of \(0\) and a variance equal to \(d_{k}\) [INDEX].For large spaces like \(d_k = 512\), the raw scores can expand to large values like \(35\) or higher. Passing these large numbers into the exponential component of the softmax function creates a severe winner-take-all peak where the largest element dominates with a probability of 1.0000, while all other weights drop to absolute 0.0000 [INDEX, INDEX]. This pushes the layer into a hard, rigid argmax assignment, forcing the mathematical derivatives (gradients) to vanish entirely, which halts model training [INDEX]. Dividing by \(\sqrt{d_{k}}\) rescales the variance back down to a clean unit value of \(1\), stabilizing the distribution [INDEX, INDEX].4. Why must the causal mask be applied before softmax?The softmax function normalizes any real numbers into a valid probability distribution where all elements sum up horizontally to exactly 1.0 [INDEX].If you attempt to mask future tokens after running the softmax layer by setting them to zero, you distort the distribution, and your remaining valid past tokens will no longer add up to \(1.0\).By applying a lower-triangular causal mask before softmax, future token positions are explicitly filled with an extremely large negative number (\(-\infty \) or \(-1e9\)) [INDEX, INDEX]. Because \(e^{-\infty} = 0\), the softmax calculation automatically drops future tokens down to a clean weight of exactly 0.00 while smoothly balancing the remaining probabilities over the allowed historical tokens [INDEX].5. Why does \(\text{weights} \times V\) produce a new representation for every token?The matrix multiplication multiplies an (N, N) attention weights matrix by an (N, d_v) Value matrix, producing a new context matrix of shape (N, d_v) [INDEX, INDEX].For each individual token row \(i\), this operation computes a linear combination across all rows of the value matrix [INDEX]:\(\text{Output}_{i}=\sum _{j=1}^{N}\text{Weight}_{i,j}\cdot \vec{v}_{j}\)Instead of treating words as isolated tokens, this step builds a context-aware representation [INDEX]. If the token "bank" places a \(0.85\) weight on "money", its output vector for that layer will physically absorb \(85\%\) of its numeric features from the "money" value payload vector, updating its internal definition live [INDEX].6.
