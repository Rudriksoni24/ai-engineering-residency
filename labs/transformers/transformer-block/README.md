## Q1: Why does the Transformer need an FFN after attention?
Attention is entirely a context-routing mechanism. It acts like a router that shifts numbers around to find links between words, but it doesn't do heavy processing on those features once they are brought together. The Feed-Forward Network (FFN) acts as the compute engine. It takes the blended context gathered by attention and applies non-linear functions to transform, store, and process those complex semantic relationships into higher-level abstract concepts.
## Q2: Why does the FFN expand ($512 \rightarrow 2048$) and then contract ($2048 \rightarrow 512$)?
Expanding into a four-times larger dimensional space creates a vast mathematical area where features become linearly separable. When the network applies the non-linear ReLU step, it easily isolates complex patterns, drops irrelevant noise, and acts as a key-value memory storage system. Contracting the space back to 512 packs that newly processed information tightly so it can be carried forward through the model.
## Q3: Why is the FFN described as position-wise?
It is position-wise because it processes every token completely independently and identically. The FFN applies the exact same weights to the token vector at index 1 as it does to index 10. It does not look at neighboring positions, make comparisons across time, or allow tokens to swap tokens at this stage. It treats each token as an isolated island of data.
## Q4: What information does the residual connection preserve?
The residual connection acts as an information highway that preserves the raw identity of the input tokens and early layer states. Because deep layers can corrupt or over-smooth subtle context, adding $x$ directly to the layer's output ensure that fundamental grammar, token identifiers, and earlier representations are never permanently lost. It also keeps an open, clean path for gradients to flow backward during training.
## Q5: Why does the Transformer need LayerNorm?
LayerNorm acts as a statistical stabilizer. Without it, continuous matrix multiplications would cause the values inside the vectors to spin out of control—either blowing up to infinity or shrinking to zero. LayerNorm forces the feature distributions of each individual token to consistently maintain a mean of 0 and a variance of 1, providing a clean and stable baseline that makes training deep networks highly predictable.
## Q6: Why must the FFN return to $d_{model}$?
It must return to $d_{model}$ to satisfy stackability constraints. Because the Transformer is designed by stacking $N$ identical modular blocks sequentially, the final output shape of one block must match the input shape of the next. Additionally, it must return to $512$ so that the final residual addition step ($x + \text{ffn\_output}$) can execute perfectly.
## Q7: What is the difference between Attention and Feed Forward in terms of communication between tokens?

* Attention is pure communication: It is a horizontal operation where tokens look across the entire timeline to talk, share context, and exchange information with one another.
* Feed Forward is pure isolation: It is a vertical operation where tokens are completely locked in silos. There is zero communication between token $i$ and token $j$.

## Q8 — Challenge: If attention already allows every token to interact with every other token, why isn't attention alone enough?
Attention alone isn't enough because interaction is not the same thing as transformation.
If you build a model consisting solely of attention layers, you create a machine that can only calculate linear weighted averages of things it has already seen. Attention simply routes and averages vectors across space. If it operates by itself, every subsequent layer merely computes averages of previous averages. This severely limits the model's capacity and eventually leads to representation collapse, where all token vectors blend into an identical, blurry mix.
The FFN introduces the non-linear function (like ReLU or GELU). It acts as a localized processor for the features that attention brings together. To use an analogy:

* Attention is the logistics team that moves the raw ingredients across the kitchen so they sit on the same counter.
* The FFN is the oven that applies heat to transform those raw ingredients into a completely new dish.

Without the FFN, the model can route data beautifully, but it completely lacks the capacity to run complex internal logic or synthesize new insights from the relationships it uncovers.
