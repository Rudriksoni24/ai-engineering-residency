What is a vector?A vector is an ordered list of numbers (coordinates) that pinpoints a specific location in a multi-dimensional space.In math: It represents a direction and a magnitude (length) from an origin point.In computer science: It is simply an array of floats (e.g., [0.23, -0.45, 0.89]). Each number in the array represents the value along a specific axis (dimension).2. What is an embedding?An embedding is a vector representation of real-world data (text, images, or audio) generated by a trained neural network.Semantic Capture: Unlike raw data, embeddings pack dense meaning into numbers. Words or concepts with similar meanings are placed close to each other in the vector space.Dimensionality Reduction: It condenses massive, sparse discrete concepts (like a dictionary of 100,000 unique words) into a compact, dense continuous space (typically 384, 768, or 1536 dimensions).3. Why cosine similarity?Cosine similarity is preferred for comparing embeddings because it measures the angle between two vectors, ignoring their scale (magnitude).Direction Over Length: It evaluates how well the vectors point in the same direction. A score of 1.0 means they point in the exact same direction (perfectly similar), 0.0 means they are orthogonal (unrelated), and -1.0 means they are opposite.Document Length Invariant: In NLP, if one text snippet repeats the word "cars" 2 times and another text repeats it 20 times, their lengths differ wildly, but their topic is identical. Cosine similarity ensures they still score as highly similar.4. Where embeddings are used in RAG (Retrieval-Augmented Generation)Embeddings are the fundamental building blocks of a RAG pipeline, acting as the bridge between external knowledge and the Large Language Model (LLM). They are used in two main stages:Ingestion (Offline Phase):Your external raw text documents (PDFs, Wikis, Docs) are broken down into small, digestible chunks.Each text chunk is passed through an Embedding Model to generate its unique vector.These vector embeddings are stored inside a Vector Database (like Chroma, FAISS, or Pinecone) linked directly to their original text chunks.Retrieval (Online/Runtime Phase):A user submits a raw Query (e.g., "How do I fix error X?").The system passes this query through the exact same Embedding Model to generate a query vector.The system runs a vector search (using Cosine Similarity) comparing the query vector against all chunk vectors in the database.The top Kcap K𝐾 most similar text chunks are pulled out and injected directly into the LLM's prompt context to generate an accurate, grounded answer

Why are embeddings vectors?Embeddings are vectors because computers cannot perform calculus or geometry on raw concepts, but they can on arrays of numbers.Geometric Relationships: Neural networks need a way to position concepts relative to one another. A vector acts as a set of spatial coordinates. By mapping "Apple" and "Orange" to nearby coordinates, the computer can geometrically calculate that they are related.Feature Representations: Each dimension in an embedding vector represents an abstract, learned feature (e.g., is_fruit, is_digital, tense, tone). A single number cannot hold multiple independent traits, but a multi-dimensional array can hold hundreds simultaneously.2. Why does RAG use embeddings instead of keyword matching?Keyword matching breaks down when users express the same intent using different vocabulary. Embeddings solve this by capturing semantic meaning.Synonyms & Context: If your document contains "The company experienced a financial downturn" and a user searches for "business losses", keyword matching scores this as a 000 match. Embeddings recognize they represent identical concepts.Polysemy Handling: Keyword search treats the word "bank" the same way whether it appears in a financial document or a geography text about rivers. Embedding models look at surrounding words to generate entirely different vectors depending on the context.Multilingual Mapping: Advanced embedding models map different languages into the exact same vector space. A query written in Spanish can retrieve the correct reference document written in English.4. Why does normalization matter?Normalization rescales a vector so that its total length (L2 norm) equals exactly 1.01.01.0. This matters for two critical engineering reasons:Massive Speed Optimization: When your vectors are pre-normalized, their magnitudes (‖𝐴‖ and ‖𝐵‖) are both 111. The denominator of the cosine similarity formula disappears entirely, turning the equation into a simple dot product (A @ B). This reduces millions of complex floating-point divisions to pure matrix multiplications, which GPUs can process instantly.Fair Comparisons: Without normalization, long vectors or vectors with unusually high element values can heavily distort distance metrics (like Euclidean distance), causing long text chunks to be unfairly penalized or favored over short ones.
