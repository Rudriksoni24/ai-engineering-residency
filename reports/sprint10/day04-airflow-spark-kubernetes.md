## 9. Engineering conclusions and limitations

The Kubernetes-hosted Airflow instance registered the existing transaction DAG, produced a completed 20-transaction report, and recovered the report from persistent storage after the Airflow Pod was replaced. Kubernetes kept the existing FastAPI Deployment and both Day 3 data claims intact.

This lab uses Airflow standalone with Spark local execution. The artifact PVC protects output files across Pod replacement; it does not protect Airflow's standalone scheduling metadata or task logs, nor does it provide distributed Spark execution, multi-node storage availability, independent backups, or production-grade Airflow high availability.
