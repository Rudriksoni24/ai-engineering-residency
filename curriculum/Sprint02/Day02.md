# Sprint 2 — Day 2

# Ollama Fundamentals and Local Models

## Goal

Install and operate a local LLM runtime.

Build the first concrete implementation of the LLMRuntime abstraction.

## Learning Objectives

By the end of this day, I should understand:

- What Ollama does.
- How models are pulled and stored locally.
- How a local model is executed.
- How the Ollama API works.
- How to connect application code to Ollama.
- Why the application should use the LLMRuntime abstraction.
